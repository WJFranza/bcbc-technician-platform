# BCBC Technician Platform

## Overview

BCBC is a technician-first learning and systems platform designed to teach real-world Linux, repair workflows, networking, and infrastructure thinking through hands-on tools.

It is built from real production experience in systems administration, recovery environments, and automation.

---

## What this project contains

### 🔧 BCBC Website
A modular, static web platform that serves as the main landing page for the BCBC ecosystem.

### 📚 BCBC Cheatsheets
A structured command and troubleshooting reference system for Linux and technician workflows.

### 🧪 BCBC AI Checker
A lightweight tool for system/AI-assisted checking and validation workflows.

### 🎓 BCBC Learning System
A bootable USB-based training and recovery environment concept for teaching real technician skills.

---

## Philosophy

Teach systems by making them visible, practical, and repeatable — not abstract or theoretical.

Focus on:
- real troubleshooting
- real systems
- real workflows
